# Virtual HR Dashboard 

A mini working web task tracking-system dashboard that connects employers with a Virtual HR.

## Features
1. Task assignment: Employers assign tasks to the Virtual HR.
2. Progress updates: The Virtual HR updates task status and progress.
3. Live monitoring: Employers track task progress in real time.
4. Interview scheduling: The Virtual HR schedules interviews through built-in modes (Voice / Video / Chat).

## Tech Stack
FastAPI · React · SQLite
